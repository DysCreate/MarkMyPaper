2. What this software is

MarkMyPaper reads uploaded answer sheets and produces similarity-based grading suggestions. In the current implementation it does the following:

  • accepts PDF, JPG, JPEG, and PNG files;
  • extracts text, using PyPDF2 for embedded PDF text and TrOCR for rendered pages and images;
  • compares the extracted text against model answers with token-level fuzzy matching, awarding full weight at 80% similarity or better, proportional weight from 70% to 79%, and nothing below 70%;
  • stores grading runs in a local SQLite database when history is enabled, which it is by default.

This version is the only version whose behavior these terms describe. The repository may change at any time.

3. Accounts and credentials

Registration stores your name, email, and a hashed password in the local database file (instance/users.db). Logging in issues a JWT that your browser keeps in local storage. Passwords are hashed with a one-way function; the application cannot recover them. You are responsible for keeping your own copy of the database and its credential records secure, since you control the machine it lives on.

5. Responsible use

Automated grading output is a measurement aid, not a final decision. You should verify low, borderline, and handwriting-heavy results against the original sheet before recording a mark. Do not present a MarkMyPaper score to a student as authoritative without review. Do not use the application in any way that violates your institution's academic integrity policies.
