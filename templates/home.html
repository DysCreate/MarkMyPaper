Pipeline

How grading happens

01

Upload the sheet

One PDF, JPG, JPEG, or PNG file per run. Text-based PDF pages are read directly; image pages and photo scans are transcribed by the OCR pass.

format enforced: pdf / jpg / jpeg / png

02

State the model answers

Enter one model answer per check and give each a weight. The weight is the most marks that answer can earn, and the answer as you type it is the reference text used for comparison.

answers and weights are matched by position

03

Extract the text

PyPDF2 pulls embedded text out of digital PDFs. Scanned pages and images are rendered and transcribed with TrOCR, a transformer model trained on handwriting. The force-OCR switch skips embedded text and transcribes every page.

text route: PyPDF2 / image route: TrOCR

04

Score each answer

The combined extracted text is compared against every model answer with token-level fuzzy matching. A similarity of 80 and above earns the full weight, 70 to 79 earns proportionally, and anything below earns nothing.

similarity 80+ full marks, 70 to 79 proportional, below 70 none

Limits worth knowing

  • Similarity is token based. Long, well-written answers against short model keys can score low even when the student is right. Model answers should stay close to the phrasing you expect.
  • Handwriting OCR is approximate. TrOCR transcribes legibility, not truth. Poor scans and mixed scripts raise error rates, so read the extracted text before trusting a low score.
  • One text stream per run. Multi-page PDFs are joined into a single text stream before scoring, so the tool scores the whole sheet, not question by question. Per-page extraction is still reported in the result.
  • First run is slow. The TrOCR model downloads once from Hugging Face on your first grading run, and transcription is heavy on CPU. Small test files are a good way to start.
  • You own the final call. Grading here is a measurement aid. The mark you record should be yours.

Self-hosted

Run it on your machine

MarkMyPaper is a small Flask application. It runs wherever Python runs, keeps its data in a local SQLite file, and processes uploaded sheets in memory on your own hardware. Cloning the repository and starting the app is the whole setup.

Users who grade sheets can skip registration entirely. An account only gates the password-protected API and attaches a name to grading records in your local database.

# requires Python 3.9+ git clone https://github.com/DysCreate/MarkMyPaper cd MarkMyPaper python -m venv .venv source .venv/bin/activate # Windows: .venv\Scripts\Activate pip install -r requirements.txt python app.py
serves on http://127.0.0.1:5000
