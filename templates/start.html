Getting started

There is no trial to unlock

MarkMyPaper is free, self-hosted software. There are no tiers, no metering, and no credit card step. Grading works immediately on the default setup. Pick whichever path fits what you are trying to do.

1

Grade a sheet right now

No account required. Open the grader, choose a PDF or image, enter model answers with weights, and run it. The results, the extracted text, and the per-page method are shown on the same page.

Open the grader
2

Create an account for API access

Registration enables the password-gated API routes and keys your session with a JWT. It is optional for grading. Your credentials and the grading history live in the local SQLite file on this machine.

Register Log in
3

Run or extend your own install

The whole application is one Flask file plus templates. Clone the repository, install the requirements, and start it. Then it is your code to compile, test, or change.

git clone https://github.com/DysCreate/MarkMyPaper cd MarkMyPaper && pip install -r requirements.txt python app.py

serves on http://127.0.0.1:5000

Before you grade, two honest notes

  • Scores measure similarity, not correctness. Use the extracted text panel and read the sheet for low, borderline, and handwriting-heavy results.
  • First run downloads a model. TrOCR is pulled once from Hugging Face on startup. Subsequent runs are faster, but transcription still uses your compute.
